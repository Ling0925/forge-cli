# 全屏终端阅读、选区与复制（Ink）

- 默认富终端进入备用屏幕，Ink/Yoga 负责固定高度消息视口和底部输入区；不启用旧手写 Screen，不捕获鼠标、不发送 OSC52。
- 退出、EOF、SIGHUP/SIGTERM 后恢复原 Shell 画面、raw/paste 模式。全屏内容不追加到 Shell scrollback，持久化会话仍可 resume/export。
- **PgUp** 打开近期历史和未完成输出的只读快照；PgUp/PgDn 翻页，**End/Esc** 返回实时界面。后台运行不暂停，冻结期间新输出不打断阅读和原生选区。
- 阅读中 Ctrl+C 只退出阅读；取消运行需回实时后再 Ctrl+C。文本/Enter 不提交草稿。
- 审批或选择器退出阅读以保证交互可见，草稿保留。审批输入固定在底部；Slash 建议在输入上方展开。
- 复制使用终端原生拖选与 Copy（例如 Ctrl+Shift+C/Cmd+C）。选区在窗口缩放时的行为依终端实现，不调用系统剪贴板程序。
- 阅读缓存最多 2000 个近期逻辑行 / 1 MB；冻结快照最多 2000 物理行。更早内容需通过会话导出获取；展示缓存限制不裁剪持久化会话。
- `INK_SCREEN_READER=true` 保持紧凑行内输出，不进入备用屏幕，不填充整屏空白；普通 run/JSON/管道和未挂载 TUI 的单次审批不进入全屏。

自动验证：Chromium/xterm 检查底部输入坐标、长短输出、Slash/审批/选择器切换、冻结选区、仅高度缩放和宽高联合缩放（含极小窗口）、混合宽字符草稿与退出后原屏恢复。SSH/tmux 和 OS 剪贴板仍需对应环境人工验收。
