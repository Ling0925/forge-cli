# 全屏终端阅读、选区与复制（Ink）

- 默认富终端进入备用屏幕，Ink/Yoga 负责固定高度消息视口和底部输入区；不启用旧手写 Screen、不发送 OSC52。
- 全屏默认启用基本鼠标按钮/滚轮报告（1000 + SGR 1006），不启用移动/拖动跟踪。只处理上下滚轮，点击不会选中操作或批准工具。
- **滚轮向上**打开近期历史和未完成输出的只读快照，每次滚动移动 3 行；向下滚到底返回实时界面。**PgUp** 也可打开阅读，PgUp/PgDn 翻页，**End/Esc** 立即返回实时界面。
- 后台运行不暂停，冻结期间新输出不打断阅读。阅读中 Ctrl+C 只退出阅读；取消运行需回实时后再 Ctrl+C。文本/Enter 不提交草稿。
- 审批或选择器退出阅读以保证交互可见，此时滚轮不会打开历史或改变选择，草稿保留。
- 开启鼠标报告后，原生选区通常需 **Shift+拖选**，然后使用终端 Copy（例如 Ctrl+Shift+C/Cmd+C）；具体修饰键取决于终端设置。Forge 不实现拖选或调用系统剪贴板程序。
- 若更偏好无修饰键的原生选区，可用 `FORGE_MOUSE=0 forge` 关闭鼠标报告，历史改用 PgUp/PgDn。关闭报告不会为备用屏幕增加原生 scrollback。
- 退出、EOF、SIGHUP/SIGTERM 后关闭本次启用的鼠标报告，恢复原 Shell 画面、raw/paste 模式。全屏内容不追加到 Shell scrollback，持久化会话仍可 resume/export。
- 阅读缓存最多 2000 个近期逻辑行 / 1 MB；冻结快照最多 2000 物理行。更早内容需通过会话导出获取；展示缓存限制不裁剪持久化会话。
- `INK_SCREEN_READER=true` 保持紧凑行内输出，不进入备用屏幕、不启用鼠标报告；普通 run/JSON/管道和未挂载 TUI 的单次审批也不启用。

自动验证包括 Chromium/xterm 滚轮事件到历史视口的往返、底部输入坐标、冻结期间输出、缩放、退出后原屏恢复，以及模式清理失败路径。SSH/tmux、具体终端的 Shift 选区手势和 OS 剪贴板仍需对应环境人工验收。
