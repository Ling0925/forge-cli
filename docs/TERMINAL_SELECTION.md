# 终端阅读、选区与复制（Ink）

- 默认界面使用主屏幕和终端原生 scrollback，不开启备用屏幕，不捕获鼠标，也不发送 OSC52 剪贴板请求。
- 已完成的回复/工具结果由 Ink 提交到 scrollback；使用终端滚轮、选择和 Copy 快捷键（例如 Ctrl+Shift+C / Cmd+C）。Forge 不读取系统剪贴板。
- 运行中按 **PgUp** 打开只读快照，包含近期已完成内容和当前未完成输出；继续 PgUp/PgDn 翻页。快照冻结绘制，后台运行不暂停，新输出暂存而不打断阅读和选择。
- **End / Esc** 返回实时界面。阅读中 Ctrl+C 只退出阅读；需要取消任务时返回实时界面后再 Ctrl+C。阅读中的文本/Enter 不提交草稿。
- 审批或任务选择器出现时会退出阅读，避免隐藏需要处理的交互；草稿保持。窗口大小改变会重新布局，原生选区是否保留由终端决定。
- 阅读缓存最多 2000 个近期逻辑行 / 1 MB；快照最多 2000 个物理行。更早的已完成内容仍在终端 scrollback 和持久化会话中，可通过 `/export` 获取。
- 阅读期间待显示输出最多 2 MB；超过时明确提示缓存溢出，持久化会话不裁剪。回到实时界面只提交尚未显示的完成输出一次，不把未完成快照追加成重复消息。
- 原来的应用内拖选自动复制、`Copyed！`、Ctrl+G 原生选择切换已移除。

自动验证覆盖：真实 Chromium/xterm 的 scrollback 唯一性、未完成内容翻页、冻结期间原生选区保持、宽高缩放、CJK/emoji 草稿恢复。未以自动测试声称每个 SSH/tmux/操作系统剪贴板组合均已验收。
